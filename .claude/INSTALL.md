# Claude Code specifics

Start with [INSTALL.md](../INSTALL.md). This file only covers what's different in Claude Code.

## Skills folder

Use `$HOME/.claude/skills` as the destination. It works in both PowerShell and Bash.

## superpowers

```bash
claude plugin install superpowers@claude-plugins-official
```

To update: `claude plugin update superpowers@claude-plugins-official`
