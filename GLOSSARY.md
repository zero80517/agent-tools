# Agent Tools

A personal collection of skills, agents, scripts and similar tools, shared across harnesses and PCs.

## Language

**Harness**:
An application that runs AI agents and loads their skills, such as Claude Code or OpenCode.
_Avoid_: Client, tool, IDE

**Usage**:
A short, reusable label saying what a skill or agent is used for, such as `plan` or `commit`. One item can have several.
_Avoid_: Tag, category

**Source**:
Where a skill or agent comes from.
_Avoid_: Origin

**DIY**:
Written and edited by the owner of this collection. Applies to skills and agents.
_Avoid_: Own, custom

**Third-party skill**:
A skill written by someone else, kept in this collection exactly as its author published it.
_Avoid_: Fork

**Required skill**:
A skill included because another skill does not work without it.
_Avoid_: Dependency

**External project**:
Someone else's whole collection that is used in full, so this collection only says how to install it.
_Avoid_: Vendored project
